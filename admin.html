管理员登录

请粘贴你的 GitHub Personal Access Token。Token 只保存在你自己的浏览器里，不会写入代码，也不会经过任何第三方。

如何创建 Token？（只需创建一次，过期后重新生成再粘贴即可）
  1. 登录 GitHub 后打开 github.com/settings/personal-access-tokens/new
  2. Token name 随意填写（如 blog-admin），设置一个过期时间
  3. Resource owner 选择 nightflee
  4. Repository access 选择 Only select repositories，勾选 nightflee/nightflee.github.io
  5. Permissions → Repository permissions → Contents 设为 Read and write
  6. 点击 Generate token，复制生成的令牌（github_pat_ 开头），粘贴到上方输入框

经典 Token（勾选 repo 权限）也同样可用。Token 等同于你对该仓库的写权限，请勿泄露给他人。
